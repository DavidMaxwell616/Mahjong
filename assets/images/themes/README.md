# Themed mahjong artwork

Created with the built-in image generation tool. Each PNG contains 50 illustrated tiles in 10 columns and 5 rows, matching the original ivory faces, painted motifs, and green lower edges.

These are generated source artwork sheets, not pixel-normalized replacements for the current 98x140 Phaser spritesheet. Tile boundaries vary slightly; the toys image also includes a narrow right margin. GameScene now defines eight curated first-row atlas frames per theme using measured column boundaries, avoiding the right margin and uneven rows. The original PNGs are preserved. Additional illustrations need their own frame bounds before runtime use.
